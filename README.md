# Lettre pour Diana — version enveloppe

## Fichiers
- `index.html` : structure du site
- `style.css` : design et animations
- `script.js` : enveloppe, texte et changement de langue

## Hébergement gratuit recommandé : GitHub Pages

GitHub Pages permet d'héberger ce site statique gratuitement avec GitHub Free dans un dépôt public.

1. Crée un compte sur GitHub si tu n'en as pas.
2. Crée un nouveau dépôt, par exemple `pour-diana`.
3. Mets `index.html`, `style.css` et `script.js` à la racine du dépôt.
4. Va dans `Settings` → `Pages`.
5. Dans `Build and deployment`, choisis `Deploy from a branch`.
6. Choisis `main` et `/ (root)`, puis `Save`.
7. GitHub te donnera l'adresse publique du site.

Tu peux ensuite envoyer simplement le lien à Diana.

## Important
Le site utilise Google Fonts via une feuille de style externe. Le site fonctionne quand même avec des polices de secours si cette ressource n'est pas disponible.
